# Spedu Labs 共用資源

此資料夾供各子目錄共用。講義字型已改由 `css/fonts.css` 統一管理（目前套用於 `eng-115/text/`、`eng-115/text-translation-match.html` 與 `test-lab/` 單字講義）；其餘頁面仍維持原樣。

- `css/workspace.css`：統一標題列、側邊分類、卡片、搜尋與響應式外觀。
- `js/workspace.js`：分類篩選、搜尋、收藏與手機側欄。
- `images/`：預留共用圖片。
- `icons/`：預留共用圖示。
- `css/fonts.css`：講義共用字型（源泉圓體 TW、Andika、Comic Neue、注音）與 `--font-zh`、`--font-en`、`--font-en-trace`、`--font-bpmf` 變數；字檔放在 `fonts/`，授權見 `fonts/NOTICE.txt`。
