【時間詞－日常時鐘報時】

班級：__________ 姓名：__________

💡 核心重點：整點、半點與 15 分的時鐘英文唸法！

o'clock

整點專用

例如 7:00 ➔ seven o'clock

half past

半點 (30分) 專用

例如 7:30 ➔ half past seven

quarter past

過一刻 (15分) 專用

例如 7:15 ➔ quarter past seven

★ 實用提示：時間也可以用簡單的「先唸小時，再唸分鐘」直接唸（例如 7:30 ➔ seven thirty）！

LEVEL 1 暖身判讀：這樣報時正確嗎？ (正確選 ◯，錯誤選 ✕)
(      )
1. We can say 8:00 is "eight o'clock".
(      )
2. We can read 9:30 as "half past nine" or "nine thirty".
(      )
3. 10:15 is "quarter to ten".
LEVEL 2 進階挑戰：時鐘報時字卡免打字配對
🖐️ 先選取字卡，再點擊題目空格：

1. It is 4:00. It is four ________ .

現在是四點整。

2. It is 5:30. It is ________ five.

現在是五點半（過五點半個小時）。

3. It is 6:15. It is ________ six.

現在是六點十五分（過六點一刻）。

4. It is 8:15. It is eight ________ .

現在是八點十五分（直接讀出分鐘）。

LEVEL 3 綜合選擇題：選出最正確的答案

(      ) 1. What time is it? (11:00) It is eleven ______ .

(      ) 2. 2:30 is ______ .

(      ) 3. 1:15 can be read as ______ .

🔑 本講義教師解答：【Level 1】1. ◯   2. ◯   3. ✕   【Level 2】1. o'clock   2. half past   3. quarter past   4. fifteen   【Level 3】1. (B)   2. (A)   3. (C)
