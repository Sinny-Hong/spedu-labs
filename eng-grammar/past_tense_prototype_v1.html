過去簡單式｜P1

什麼是過去式？

班級：__________　姓名：__________
過去式：表示過去發生的事情，或描述過去的狀態。
先看三個句子
1.
I was a student before.
我以前是一名學生。
2.
I played basketball yesterday.
我昨天打籃球。
3.
Did you play basketball yesterday?
你昨天有打籃球嗎？
這三句都是過去式。常看到：was / were　V-ed　did
這一頁先只認得 before＝以前、yesterday＝昨天。其他過去時間之後再整理。
一、找出表示過去式的動詞
1.I was tired yesterday.
2.We were classmates before.
3.Amy played tennis yesterday.
4.Did you study yesterday?
5.They went home yesterday.
二、判斷句子是不是過去式
○×（　　）1.I play basketball every day.
○×（　　）2.She is watching TV now.
○×（　　）3.He was tired yesterday.
○×（　　）4.They visited Grandma yesterday.
○×（　　）5.We are students.

原形長這樣怎麼變例子
大部分動詞＋ edplay → played
已經是 e 結尾＋ dlike → liked
子音＋yy → iedstudy → studied
不規則另外記go → went
常用不規則：go → wentsee → saweat → atehave → had

1. play →
2. like →
3. study →
4. go →
5. see →
二、把現在式改成過去式

→

2. Amy likes dogs.
→

3. We study English every day.
→

4. They go home every day.
→

1. Did you（play／played）basketball yesterday?
2. Did Amy（like／liked）the movie?
3. Did he（study／studied）English yesterday?
4. Did they（go／went）home?
5. Did you（see／saw）Kevin?
