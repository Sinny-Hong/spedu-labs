# 異想聊天室 eChat｜20 關「降風險求生版」總劇本

## 用途
此檔為明日交給 Worker / Codex 寫回既有四套 HTML 的唯一文本來源。

## 共同編劇規則
- 每套 5 關，每關固定 5 階段。
- 每階段 3 個選項：紅／黃／綠是風險分類，不是單純「錯／半對／對」。
- 黃燈必須是真正可理解、可暫時降低風險的策略，不是假裝成第三個錯誤答案。
- 正確／安全策略可包含：裝傻、找藉口、拖延、轉移、離開、不回覆、查證、找朋友商量、找家人或可信任的大人、使用正式管道。
- 五格是五次判斷，不是五次固定升級。
- 出現明確人身安全、自傷、私密影像勒索、金錢／帳密等重大風險時，依情況升級求助。
- 不要求學生當英雄；目標是把風險降下來。
- 選項必須像國中生真的說得出口的話。
- 作答前 UI 不顯示紅／黃／綠；學生選完才揭露分類與回饋。
- UI 呈現順序不得固定對應風險等級；程式端需隨機排列三個選項，但答案／回饋／風險 metadata 必須跟著選項一起移動。
- 同一階段重新嘗試時是否維持原排序，由程式實作統一決定；建議該階段首次呈現時洗牌一次，重試不再洗牌，避免學生閱讀位置一直跳動。

# 關卡一｜假玩笑真越界

**主題：** 身體界線與同儕壓力\
**對方：** 同班同學阿翔（平常愛打鬧、有點痞）\
**情境：** 阿翔今天下課教了你一題很難的數學，晚上突然傳訊息來。

## 階段 1｜試探底線

**阿翔：**「欸，我今天數學教你那麼多，有沒有很感動？你打算怎麼報答我啊？」

-   🔴 **紅燈｜順口答應**\
    「感恩啦兄弟！你想要什麼報答隨便你說～」\
    **回饋：**
    先別把話說太滿。你都還不知道他要什麼，先答應反而容易讓自己不好收回。

-   🟡 **黃燈｜裝傻帶過**\
    「蛤？報答什麼？你才教我一題而已欸。」\
    **回饋：** 這招可以。先裝傻、不急著接他的話，幫自己留一點空間。

-   🟢 **綠燈｜把範圍說清楚**\
    「謝啦，明天請你喝一杯手搖飲當報答。」\
    **回饋：**
    很清楚。直接講一個自己可以接受的方式，不用讓「報答」變成什麼都得答應。

## 階段 2｜言語越界

**阿翔：**「飲料太無聊了啦！既然是好哥們，明天放學去樓梯間讓我摸一下胸部當報償啦！開個玩笑摸一下沒差吧？」

-   🔴 **紅燈｜退一步討價還價**\
    「太瞎了吧！好啦只能碰一下肩膀喔，不能亂摸。」\
    **回饋：** 你明明已經不舒服了，就不用拿自己的身體跟他討價還價。

-   🟡 **黃燈｜直接下線**\
    「太噁了吧，我不想理你了，我要去睡覺了，掰。」\
    **回饋：** 可以先閃。遇到讓你不舒服的話題，本來就不用陪對方聊到底。

-   🟢 **綠燈｜簡單踩住界線**\
    「這玩笑很難笑欸。不要亂講話。」\
    **回饋：** 夠清楚，而且不用講一大串。讓他知道你不接受這種玩笑就好。

## 階段 3｜見笑轉生氣

**阿翔：**「幹嘛那麼認真啦？開個玩笑而已也生氣喔，真的是開不起玩笑欸，有夠掃興。」

-   🔴 **紅燈｜反過來道歉**\
    「對不起啦......我只是對這種事比較敏感，你不要生氣。」\
    **回饋：** 先不用急著道歉。是他的話讓你不舒服，不代表你反應太大。

-   🟡 **黃燈｜敷衍離開**\
    「喔，隨便你怎麼想，反正我先去洗澡了。」\
    **回饋：**
    不想吵就先離開也可以。你不需要留下來證明自己「開得起玩笑」。

-   🟢 **綠燈｜把問題說回去**\
    「因為這本來就不好笑啊。你去找覺得好笑的人開玩笑吧。」\
    **回饋：** 有把界線講清楚，也沒有被他帶去爭論「是不是你太敏感」。

## 階段 4｜同儕恐嚇

**阿翔：**「你這女的真的很難搞。你要是敢去跟別人亂講，我就跟全班說你公主病、難相處，看以後分組誰理你！」

-   🔴 **紅燈｜為了息事寧人答應保密**\
    「好啦我不說就是了，你不要亂講話。」\
    **回饋：**
    他已經開始拿同學關係威脅你了。這時候答應保密，反而會讓你更孤立。

-   🟡 **黃燈｜找信任的朋友一起判斷**\
    「（先不回阿翔）把截圖傳給好朋友：『欸阿翔傳這個給我，我有點不知道怎麼辦。』」\
    **回饋：**
    不確定怎麼處理時，可以先找信任的人一起看。至少不用一個人被他的話嚇住。

-   🟢 **綠燈｜冷處理並保留訊息**\
    「隨便你，反正對話我都留著。」\
    **回饋：** 不跟他繼續吵，也讓他知道這些訊息不是說完就消失。

## 階段 5｜安全威脅

**阿翔：**「截圖又怎樣？你去告狀啊！明天到學校你就死定了！」

-   🔴 **紅燈｜刪掉逃避**\
    「（嚇到）趕快把對話全刪了，明天裝病請假不去學校。」\
    **回饋：**
    害怕很正常，但先不要把訊息刪掉。少了紀錄，之後反而更難請別人幫忙。

-   🟡 **黃燈｜先確保自己不落單**\
    「（明天到學校）先跟好朋友一起走，不跟阿翔單獨相處。」\
    **回饋：**
    不落單是有用的自保方法，但他已經直接威脅你的人身安全，不能只靠朋友陪著。

-   🟢 **綠燈｜找能實際介入的人**\
    「（先不回）把截圖給爸媽或信任的大人看：『同學傳這個恐嚇我，我明天去學校有點害怕。』」\
    **回饋：**
    這已經不是普通吵架了。有人直接威脅你明天的安全，就要讓能實際介入的人知道。

# 關卡二｜說不清的曖昧

**主題：** 曖昧、肢體界線與情緒控制\
**對方：** 補習班同學小宇（每天晚上都會用 LINE 聊天）\
**情境：**
今天補習下課過馬路時，小宇突然牽了你的手。回家後，他傳訊息來。

## 階段 1｜單方面確認關係

**小宇：**「今天過馬路時我牽你的手，你沒甩開。那我們現在算是在一起了吧？女朋友
❤️」

-   🔴 **紅燈｜怕尷尬就順著答應**\
    「嗯......應該算吧，有點害羞。」\
    **回饋：**
    如果你自己都還不確定，就不用因為怕尷尬先答應。答應之後反而更難說清楚。

-   🟡 **黃燈｜裝傻爭取時間**\
    「蛤？有牽手嗎？我那時候在看旁邊的狗欸。」\
    **回饋：**
    還沒想清楚時，先裝傻帶過也可以。不需要被一句「女朋友」逼著馬上決定。

-   🟢 **綠燈｜把自己的意思說清楚**\
    「我那時只是因為車子很多嚇到，沒有別的意思，你不要想太多啦。」\
    **回饋：**
    直接把自己的意思說清楚，不讓一次牽手自動變成「已經交往」。

## 階段 2｜強行升級互動

**小宇：**「不管啦，反正你沒有拒絕。明天去補習班，我要在大家面前直接抱你喔！」

-   🔴 **紅燈｜勉強答應一點**\
    「太快了啦......只能在沒人的地方抱一下喔。」\
    **回饋：** 如果你其實不想被抱，就不用為了怕他失望而答應「一點點」。

-   🟡 **黃燈｜拿外在理由擋一下**\
    「不要啦，補習班人那麼多，被老師看到會被罵欸。」\
    **回饋：**
    拿規定或別人當擋箭牌，也是一種脫身方法。只是如果他換個地方繼續要求，你還是要想清楚自己到底願不願意。

-   🟢 **綠燈｜直接說自己不要**\
    「我不想這樣，明天不要突然抱我，我會很尷尬。」\
    **回饋：** 很清楚。前一次沒有甩開他的手，不代表下一次就同意被抱。

## 階段 3｜質疑與情緒綁架

**小宇：**「你是不是根本就不喜歡我？只是想玩弄我的感情？我以為我們每天聊天就是互相喜歡欸。」

-   🔴 **紅燈｜為了安撫而妥協**\
    「我沒有玩弄你啦！對不起，那我明天試著配合你。」\
    **回饋：**
    如果每次他一難過，你就得答應原本不想做的事，這段關係會越來越累。

-   🟡 **黃燈｜先不要現在決定**\
    「我現在腦袋有點亂，不知道怎麼回你，我先去睡覺了。」\
    **回饋：**
    可以先停。被逼著馬上回答時，晚一點再決定通常比勉強答應安全。

-   🟢 **綠燈｜說出自己的關係定位**\
    「每天聊天不代表就是要交往吧？我覺得我們當朋友比較好。」\
    **回饋：**
    把自己的想法說清楚。喜不喜歡、要不要交往，都不是由對方單方面決定。

## 階段 4｜自傷威脅

**小宇：**「（傳送一張站在頂樓邊緣的照片）如果你明天拒絕我，我就從這裡跳下去，讓你知道我有多難過！」

-   🔴 **紅燈｜自己扛下來並妥協**\
    「你不要做傻事！我答應你就是了，你趕快下去！」\
    **回饋：**
    你可以擔心他，但不用用「答應交往」來換他的安全。這已經不是你一個人能處理的事。

-   🟡 **黃燈｜只找同學幫忙**\
    「趕快傳給另一個補習班同學：『欸小宇好像怪怪的，你知道他在哪嗎？』」\
    **回饋：**
    找知道他狀況的人是合理的第一反應，但涉及立即的人身安全時，不能只停在同學之間。

-   🟢 **綠燈｜立刻把危險交給能介入的人**\
    「立刻拿照片給家人看，並聯絡補習班老師、小宇家人或緊急協助管道，說：『他傳這張照片說要跳下去，我不知道他在哪裡。』」\
    **回饋：**
    這種訊息要當真處理。你不用自己判斷他是不是在演，也不用一個人負責把他勸下來。

## 階段 5｜跑到住家附近

**小宇：**「都不回訊息是怎樣？我現在在你家樓下，你不下來跟我說清楚，我就一直在這裡等你！」

-   🔴 **紅燈｜自己下樓處理**\
    「好啦你別吵，我現在偷偷溜下去找你，你不要叫。」\
    **回饋：**
    他現在情緒不穩，又直接跑到你住的地方，這時候不要自己出去面對。

-   🟡 **黃燈｜先用訊息拖住，但不出門**\
    「我現在不方便下去，你先回去，有事明天再說。」\
    **回饋：**
    先不出門是對的。不過他已經跑到你家附近，光靠訊息不一定能把風險處理掉。

-   🟢 **綠燈｜讓家人知道並保持距離**\
    「（不出門）立刻告訴家人：『有個補習班同學跑來我們家樓下，我不想下去見他。』」\
    **回饋：**
    這時候不用怕尷尬。讓身邊能實際保護你的人知道，比自己偷偷下樓安全得多。

## 本輪微調紀錄

1.  保留 Gemini 的五階段與紅／黃／綠三選項架構。
2.  將「黃燈」定位成可理解、可暫時降風險的策略，而不是另一種錯誤答案。
3.  降低「太神了、完美、滿分」等 AI 式稱讚，改成自然、短一點的回饋。
4.  刪弱「男生相處就......」等可能造成性別刻板印象的說法，改成對任何人都適用的界線原則。
5.  不把「第一次答應／退讓」寫成必然導致下一次，而改成尊重當下意願。
6.  自傷威脅屬高風險：保留五格劇情，但不把「只找同學」當足夠處理；綠燈改為立即交給能實際介入的人。
7.  最後一格刪除「騙對方自己不在家」作為推薦黃燈，避免對方若已在現場反而發現說謊而升高衝突；改成「不出門＋拖延」。
8.  「找老師」不再是固定終點；依情境可找家人、信任的大人、當事人家屬、正式協助管道等。

# 關卡三｜愛我就要證明
**主題：** 私密照與同儕壓力  
**對方：** 同校學長「柏翰」  
**情境：** 你們剛交往一個月，今天晚上聊天時，他突然把話題繞到了奇怪的地方。

## 階段 1｜鋪陳壓力
**柏翰：**「寶貝，我們在一起一個月了，大家都在說交往就是要沒有秘密啊。我們之間應該很坦誠吧？」

- 🔴 **紅燈｜順著答應**  
  「對啊，情侶本來就不該有秘密。」  
  **回饋：** 先別把話說太滿。就算在交往，每個人還是可以保留自己的隱私。

- 🟡 **黃燈｜打太極**  
  「喔，是沒什麼秘密啦，幹嘛突然講這個？」  
  **回饋：** 先不急著答應，看看他到底想說什麼，也是在幫自己留空間。

- 🟢 **綠燈｜先講界線**  
  「呃……可是每個人還是要有自己的隱私吧。」  
  **回饋：** 很自然。交往不等於什麼事情都必須交代或分享。

## 階段 2｜索要私密照
**柏翰：**「那你拍一張洗澡的照片給我看嘛，我發誓絕對不會存下來。我兄弟他們的女友都會傳欸！」

- 🔴 **紅燈｜相信承諾後傳送**  
  「好……但你要發誓看一眼就刪掉，絕對不能存喔。」  
  **回饋：** 照片一旦傳出去，你就很難控制它之後會不會被保存、翻拍或轉傳。

- 🟡 **黃燈｜直覺拒絕**  
  「蛤，不要啦，很奇怪欸。」  
  **回饋：** 覺得怪怪的就先不要。你不需要先想出一大套理由才有資格拒絕。

- 🟢 **綠燈｜明確拒絕**  
  「我不要。這跟別人怎麼做沒關係。」  
  **回饋：** 很清楚。別人的情侶怎麼做，不代表你也必須照做。

## 階段 3｜質疑與情緒勒索
**柏翰：**「你不傳就是不夠愛我！別人都可以就你不行？難道你對我不是真心的？」

- 🔴 **紅燈｜為了證明而退讓**  
  「我是真心的啦……不然我拍一張只露肩膀的好了。」  
  **回饋：** 你不需要用照片證明感情。原本不想做的事，也不用因為被質疑就改口答應。

- 🟡 **黃燈｜先離開話題**  
  「我現在不想聊這個，我很睏要先去睡覺了，晚安。」  
  **回饋：** 可以先停。對方一直施壓時，先離開聊天室，比被逼著馬上決定安全。

- 🟢 **綠燈｜說出不舒服**  
  「不傳照片不代表不愛吧。你這樣逼我讓我很不舒服。」  
  **回饋：** 把自己的感受說清楚，也讓對方知道這個要求已經越過你的界線。

## 階段 4｜拿分手當籌碼
**柏翰：**「連一張照片都不給，我看我們也不用在一起了。我去找願意傳給我的女生好了！」

- 🔴 **紅燈｜害怕失去而傳送**  
  「拜託不要分手！我傳就是了……」  
  **回饋：** 如果你本來不想傳，就不要因為害怕分手交出自己之後收不回來的東西。

- 🟡 **黃燈｜冷處理**  
  「隨便你，你要這樣想我也沒辦法。」  
  **回饋：** 不跟著他的威脅跑，也是一種止損。至少你沒有因為害怕失去他而改變底線。

- 🟢 **綠燈｜接受關係結束**  
  「那就分手吧。」  
  **回饋：** 如果維持關係的條件是交出你不願意給的私密內容，離開這段關係也是保護自己。

## 階段 5｜惡意抹黑
**柏翰：**「隨便你！你以後在學校最好小心一點，我會跟全校男生說你多難搞、多假掰。」

- 🔴 **紅燈｜被威脅逼回關係**  
  「不要這樣啦！那我們不要分手了，你不要亂講好不好？」  
  **回饋：** 害怕流言很正常，但不要因為威脅就回到自己不想要的關係裡。

- 🟡 **黃燈｜先不跟他糾纏**  
  「隨便你，我不想再跟你吵了。」  
  **回饋：** 先結束對話可以避免繼續被刺激。如果之後真的出現流言或騷擾，再找可信任的人一起處理。

- 🟢 **綠燈｜留訊息並找支持**  
  「（不再回覆，把訊息留著）傳給信任的朋友或大人：『他現在說要在學校亂講我，我有點不知道怎麼辦。』」  
  **回饋：** 不需要自己扛。先把訊息留下，再找一個你信任、能陪你想辦法的人。

# 關卡四｜恐怖控制
**主題：** 過度佔有、限制與自傷威脅  
**對方：** 班對男友「小傑」  
**情境：** 你們在班上公開交往。今天體育課後，他氣沖沖地傳訊息來。

## 階段 1｜無端吃醋
**小傑：**「喂，你剛剛體育課為什麼跟那個男生打球笑那麼開心？你們到底什麼關係？」

- 🔴 **紅燈｜為了安撫而放棄正常交友**  
  「對不起啦，我以後不跟男生說話了，你別生氣。」  
  **回饋：** 為了讓他不生氣就放棄正常交友，會讓自己的空間越來越小。

- 🟡 **黃燈｜簡單解釋**  
  「就剛好分到同一組啊，沒什麼啦。」  
  **回饋：** 很日常的回答。先說明發生什麼事，不需要為正常互動一直道歉。

- 🟢 **綠燈｜指出反應太大**  
  「只是同學一起打球而已，你幹嘛這麼生氣？」  
  **回饋：** 把事情拉回事實：只是一起打球，不需要接受對方把正常互動變成審問。

## 階段 2｜限制自由
**小傑：**「我不管，你現在立刻退他 IG 追蹤，而且以後都不准跟班上其他男生講話！」

- 🔴 **紅燈｜完全照做**  
  「好，我退追蹤就是了，你滿意了吧？」  
  **回饋：** 為了平息他的情緒而接受不合理限制，自己的交友空間可能會越來越小。

- 🟡 **黃燈｜先中斷爭吵**  
  「蛤？太誇張了吧，大家都在同一班欸。我不想理你了。」  
  **回饋：** 先不跟他繼續吵，也成功擋下這次要求。不過這種控制如果一直出現，就需要重新想想這段關係。

- 🟢 **綠燈｜說清楚界線**  
  「這要求很不合理，我交什麼朋友是我的自由。」  
  **回饋：** 很清楚。交往不代表另一個人可以決定你能跟誰說話。

## 階段 3｜以死相逼
**小傑：**「你果然喜歡他！你如果不照做，我明天就不去上學，或者去頂樓跳下去，讓你內疚一輩子！」

- 🔴 **紅燈｜自己扛下威脅**  
  「不要做傻事！我答應你就是了，求你別衝動！」  
  **回饋：** 你可以擔心他，但不用靠答應他的控制要求來換取安全。這種話已經不能只當成情侶吵架。

- 🟡 **黃燈｜先不答應要求，並找人一起判斷**  
  「你不要講這種話嚇我。我先不跟你吵了。」  
  **回饋：** 先停止被他逼著做決定是對的；但他已經提到跳樓，接下來不能只靠自己觀察。

- 🟢 **綠燈｜把自傷威脅交給能介入的人**  
  「我不知道你是不是認真的，但我會把你剛剛說的話告訴能幫你的人。」  
  **回饋：** 只要出現明確的自傷威脅，就不需要自己判斷真假，也不用答應交往條件來安撫他。

## 階段 4｜推卸責任
**小傑：**「你竟然真的要跟別人講？會變這樣都是你害的！如果你乖乖聽話，我會這樣嗎？我都是因為太愛你才會吃醋啊！」

- 🔴 **紅燈｜把責任全背到自己身上**  
  「嗯……可能真的是我沒考慮到你的感受，對不起。」  
  **回饋：** 他的威脅和控制不是你的責任。你可以在乎他的感受，但不需要替他的行為負責。

- 🟡 **黃燈｜中斷對話**  
  「我不想跟你吵這個了，我先下線。」  
  **回饋：** 可以先離開。但前面已經出現自傷威脅，所以「下線」不能取代找人協助。

- 🟢 **綠燈｜拒絕接下責任**  
  「你生氣可以，但不能拿跳樓來逼我照你的話做。」  
  **回饋：** 把問題說得很清楚：有情緒可以，但不能用傷害自己來控制另一個人。

## 階段 5｜立即危險
**小傑：**「（傳來一張站在高處往下拍的照片）我數到三，你不打電話過來我就跳下去！3……2……」

- 🔴 **紅燈｜只靠自己處理**  
  「（馬上打語音電話過去，答應他的要求，希望先把他勸下來）」  
  **回饋：** 這已經是立即危險，只靠你一個人扛著處理不夠，也不需要用答應他的要求交換安全。

- 🟡 **黃燈｜只向同學求救**  
  「（趕快傳訊息問好朋友：『小傑好像真的要跳，怎麼辦？』）」  
  **回饋：** 嚇到先找朋友很正常，但朋友也可能不知道怎麼處理。不要停在這一步。

- 🟢 **綠燈｜立即尋求能實際介入的協助**  
  「（保留訊息）立刻告訴身邊的大人，並聯絡小傑家人或緊急協助管道，把照片和已知位置交給能立即介入的人。」  
  **回饋：** 這是立即的人身安全危機。現在的目標不是處理感情問題，而是盡快讓能到現場、能提供緊急協助的人知道。

## 本輪微調紀錄
1. 私密照題刪除「求饒會讓對方更想欺負你」等可能責怪受害者的說法；害怕、求饒本身不是受害者的錯。
2. 不把「只露肩膀」本身描述成必然危險，而聚焦於「原本不願意卻因壓力退讓」。
3. 黃燈維持可理解、能暫時降風險的策略，不當成另一個笨答案。
4. 關卡四原稿在階段 3 已出現明確跳樓威脅，不能等到階段 5 才第一次要求求助；因此保留五階段，但從階段 3 起就進入紅線處理。
5. 階段 4 改成「因你求助而責怪你」，讓五階段劇情連續，而不是已出現自傷威脅後又退回普通情侶爭吵。
6. 自傷威脅不教學生判斷真假，也不把維持關係、答應要求或獨自安撫當成責任。
7. 最終立即危險不只限定「家長／導師」，改成能實際介入的家人、大人與緊急協助管道。

# 關卡五｜拒絕報復
**主題：** 面對惡意、孤立與人身威脅  
**對方：** 同班同學「阿威」  
**情境：** 昨天阿威當眾跟你告白，你明確拒絕了他。今天放學後，他傳來訊息。

## 階段 1｜惱羞成怒
**阿威：**「欸，我昨天跟你告白你居然敢拒絕我？讓我超沒面子！你以為你長得多好看啊？」

- 🔴 **紅燈｜為了安撫他而否定自己**  
  「對不起啦……我沒有覺得自己好看，我們還是可以當朋友啊。」  
  **回饋：** 拒絕交往本來就是你的選擇，不需要靠貶低自己來安撫他的情緒。

- 🟡 **黃燈｜直接回一句**  
  「蛤？我有拒絕的權利吧，你幹嘛那麼生氣。」  
  **回饋：** 這反應很合理，也把事實講出來了。不過他正在氣頭上，繼續回嘴可能會變成口水戰。

- 🟢 **綠燈｜重申立場**  
  「我昨天已經講清楚了，我現在不想交男朋友。」  
  **回饋：** 夠清楚。不用為拒絕找一大堆理由，也不用陪他爭誰對誰錯。

## 階段 2｜排擠威脅
**阿威：**「好啊，你給我記住。我明天就跟全班說你私底下多隨便，還要叫大家退你 IG 追蹤！」

- 🔴 **紅燈｜為了停止威脅而答應補償**  
  「你不要亂講啦……那我要怎樣你才肯不要弄我？」  
  **回饋：** 害怕很正常，但不要因為他的威脅，就讓他開始決定你必須做什麼來「補償」他。

- 🟡 **黃燈｜假裝不在乎**  
  「隨便你，愛退就退。」  
  **回饋：** 不讓他看到你被牽著走，也是一種脫身方法。如果事情真的開始擴大，再找信任的人一起處理。

- 🟢 **綠燈｜結束對話**  
  「這太瞎了吧，隨便你講，我不想理你了。」  
  **回饋：** 不繼續陪他吵，就是在降風險。你沒有義務一直留在聊天室裡接受威脅。

## 階段 3｜網路發酵
**阿威：**「我已經叫我那群兄弟發限動酸你了啦，你就等著在班上變邊緣人吧！」

- 🔴 **紅燈｜公開對罵**  
  「（立刻在自己的限動發文跟他對罵）」  
  **回饋：** 公開互罵會讓更多人被捲進來，也讓事情更難停下來。

- 🟡 **黃燈｜找朋友確認狀況**  
  「（私訊好朋友）『欸阿威說他們在限動酸我，你有看到嗎？』」  
  **回饋：** 先確認到底發生了什麼很合理，也能讓自己不要一個人亂猜、越想越怕。

- 🟢 **綠燈｜停止互動並留紀錄**  
  「（不回阿威，把威脅訊息和相關限動留存下來）」  
  **回饋：** 先不要被拉進對罵，把發生過的事情留下來，之後如果需要處理才有東西可以說明。

## 階段 4｜條件勒索
**阿威：**「怕了吧？如果你明天早自習在全班面前跟我道歉，然後買一星期的早餐給我，我就叫他們刪掉限動。」

- 🔴 **紅燈｜花錢換停止**  
  「好……我買就是了，你們快點刪掉。」  
  **回饋：** 不要因為害怕就接受用錢或其他條件交換停止騷擾。這會讓對方發現威脅能換到東西。

- 🟡 **黃燈｜拒絕但回嗆**  
  「我才不要，你當我白痴喔。」  
  **回饋：** 至少你沒有答應。不過繼續互嗆可能又開啟下一輪爭執。

- 🟢 **綠燈｜拒絕條件**  
  「這太誇張了，我不會買早餐給你，也不會道歉。」  
  **回饋：** 把不合理的要求拒絕掉就好，不需要跟他討價還價。

## 階段 5｜人身威脅
**阿威：**「這麼屌？那你明天放學最好走快一點，我會找人去校門口堵你！」

- 🔴 **紅燈｜刪掉訊息自己躲**  
  「（很害怕，把對話刪掉，明天裝病不去學校）」  
  **回饋：** 想躲開很正常，但先不要把訊息刪掉。這已經牽涉到你明天的人身安全，需要有人一起處理。

- 🟡 **黃燈｜先避免落單**  
  「（明天放學找幾個好朋友陪自己一起走）」  
  **回饋：** 不落單確實能增加安全感，但如果對方真的找人堵你，朋友也可能一起陷入危險，不能只靠這一步。

- 🟢 **綠燈｜讓能介入的人知道**  
  「（保留截圖，傳給家人或學校裡信任的大人）『他說明天放學要找人堵我，我有點怕。』」  
  **回饋：** 這已經跨到人身安全紅線。讓能安排接送、校內安全或其他協助的人提前知道，比明天自己碰運氣安全。

## 微調紀錄
- 刪除「你表現害怕就會讓他勒索你」等可能責怪被威脅者的說法。
- 「朋友陪走」保留為黃燈，但人身威脅不能只停在同儕互助。
- 降低「完美判斷」等稱讚式回饋。

# 關卡一｜遊戲網友
**主題：** 點數與借錢詐騙  
**對方：** 網友「阿凱」  
**情境：** 週末晚上，跟你一起打遊戲認識三週的網友阿凱，突然連發好幾則緊急訊息。

## 階段 1｜緊急故事
**阿凱：**「救命啊！我剛剛出門不小心把媽媽的機車弄壞了，現在在車行修理，但我不敢跟家裡說……」

- 🔴 **紅燈｜馬上把自己捲進去**  
  「天啊！那怎麼辦？需要我幫你出修理費嗎？」  
  **回饋：** 關心沒有錯，但還沒弄清楚事情，就主動把自己的錢放進去，風險會一下變高。

- 🟡 **黃燈｜先聽聽看**  
  「蛤？真假？太衰了吧。」  
  **回饋：** 先別急著幫忙，看看他接下來到底想要什麼。

- 🟢 **綠燈｜把問題送回現實生活**  
  「那你應該先找你家人吧？跟我說我也沒辦法修車啊。」  
  **回饋：** 很合理。這種現實中的緊急狀況，應該先找真正能到場處理的人。

## 階段 2｜要求買點數
**阿凱：**「拜託啦！你現在去巷口超商，幫我買一張 1,000 元的遊戲點數卡，把背面密碼拍照傳給我就好！」

- 🔴 **紅燈｜照做**  
  「喔喔好！那你等我一下，我穿個外套去超商買給你！」  
  **回饋：** 先停。點數序號一旦傳出去，通常就很難追回，而且「修機車卻要遊戲點數」本身就很不合理。

- 🟡 **黃燈｜用沒錢推掉**  
  「1000 太貴了吧，我哪有那麼多錢可以借你。」  
  **回饋：** 用「我沒錢」先拒絕很實際。不過如果他接著改口叫你「有多少買多少」，就更要警覺。

- 🟢 **綠燈｜抓到矛盾**  
  「太怪了吧，修機車為什麼要用遊戲點數付錢？」  
  **回饋：** 這個矛盾值得停下來查證。越急著叫你買點數、傳序號，越不要照著做。

## 階段 3｜情緒勒索
**阿凱：**「因為老闆說他有在玩這個遊戲，可以抵帳啦！我們不是好兄弟嗎？我明天立刻還你！」

- 🔴 **紅燈｜改成少買一點**  
  「那……我先幫你買 300 的可以嗎？」  
  **回饋：** 金額變小不代表風險消失。你原本覺得不合理，就不用靠少付一點來妥協。

- 🟡 **黃燈｜搬家人出來擋**  
  「可是我現在出門會被我媽罵欸，我沒辦法啦。」  
  **回饋：** 這招很實用。借家人當擋箭牌，也可以先把自己從壓力裡拉開。

- 🟢 **綠燈｜直接拒絕**  
  「這聽起來很像詐騙欸，我不會去買。」  
  **回饋：** 覺得不對勁就停，不需要因為「好兄弟」三個字證明義氣。

## 階段 4｜製造恐慌
**阿凱：**「你不幫我買，我現在就要被老闆打死了！你怎麼這麼沒義氣！快點啦！」

- 🔴 **紅燈｜被催促後立刻照做**  
  「好好好你別慌，我現在馬上去，你等我！」  
  **回饋：** 越是催你「現在、立刻、不要想」，越要先停下來，不要在慌張時付款或傳資料。

- 🟡 **黃燈｜找別人一起看**  
  「（截圖問朋友）『欸這個是不是怪怪的？他一直叫我買點數。』」  
  **回饋：** 自己拿不準時，先找別人一起看是好方法；也可以改用可靠的反詐資訊或 165 查證。

- 🟢 **綠燈｜把真正的緊急處理方式說回去**  
  「你如果真的有危險就找警察或家人，我不會買點數。我要下了。」  
  **回饋：** 如果真的有人身危險，應該找能實際處理的人；買遊戲點數並不能解決這種危險。

## 階段 5｜翻臉
**阿凱：**「廢物！連這點小忙都不幫，我看錯你了，以後別想跟我組隊！」

- 🔴 **紅燈｜留下來對罵**  
  「你罵誰廢物啊！你才騙子！」

- 🟡 **黃燈｜淡淡結束**

# 關卡二｜神祕官方帳號

**對方：**「福利發送中心」（頭貼是熱門遊戲圖案的陌生帳號）  
**情境：** 你在 IG 或短影音平台看到「私訊免費領 5000 鑽石」的廣告，好奇點進去私訊對方。

# 關卡三｜班上同學

**小潔：**「欸！我剛剛在社團看到一張偷拍照，長得超像你的！你快點進這個網址看：[陌生縮網址]」

  「什麼偷拍照？你先截圖給我看啊。」

- 🟢 **綠燈｜察覺說話方式不對**  
  「你怎麼突然傳這種奇怪網址？這不像你會講的話。」

**小潔：**「我就是小潔啦！你很囉嗦欸，不看就算了，活該照片被全校看光光！」

  **回饋：** 這就是換管道查證。重點是不要使用可疑訊息裡新提供的聯絡方式或連結。

  **回饋：** 已經決定不點，就不用再花時間跟可疑帳號吵架。

  「（不再回覆，先把這個對話靜音或暫時不理）」  
  **回饋：** 先切斷催促是安全的。如果你還不確定是不是本人，等確認後再決定要不要封鎖。

- 🟢 **綠燈｜本人查證並提醒**  
  「（不點網址）用原本的聯絡方式或隔天當面問小潔：『你昨天是不是有傳奇怪網址？』」  
  **回饋：** 先確認本人。如果真的是帳號被冒用或被盜，也能提醒她趕快處理，而不是直接把真正同學永久封鎖。

# 關卡四｜親密網友

**對方：** 網友「宇辰」

**宇辰：**「我們認識一個月了，我把你當成最重要的人。今天我也想看一點『特別的』，你可以去浴室拍一張沒穿衣服的照片傳給我嗎？」

  **回饋：** 如果你沒有傳出私密影像、也沒有交出帳密或安裝可疑東西，先停止接觸是合理的做法。若對方持續騷擾、掌握你的真實資料或威脅升級，再找可信任的大人或正式管道協助。

# 關卡五｜陌生玩家

**黑哥：**「你明天最好乖乖把你的神級裝備全部交易給我，不然放學我就找人去校門口堵你，把你打到進醫院！」

## 階段 5｜威脅住家
**黑哥：**「我現在馬上叫我道上的兄弟去你家附近等你，你躲不掉啦！」

- 🔴 **紅燈｜接受挑釁約出去**  
  「我才不怕！你有種就約地方，我跟你講清楚。」

- 🟡 **黃燈｜留在安全處但自己硬撐**  
  「（待在安全的地方、不出去，但什麼都不跟家人說）」  
  **回饋：** 不出去是對的；但對方已經把威脅延伸到住家附近，自己一個人扛沒有必要。

- 🟢 **綠燈｜立即讓身邊大人與適當緊急管道處理**  
  「（立刻告訴家人，提供先前保留的訊息；如果懷疑對方正在附近或有立即危險，請大人協助聯絡警方等緊急管道）」  
  **回饋：** 這時候重點是現場安全，不是再判斷他是不是吹牛。讓能實際到場或安排保護的人接手。

## 本輪微調紀錄
1. 親密網友篇不接受「對方根本拿你沒轍」作為絕對前提。若沒有傳照片、帳密或安裝可疑內容，封鎖通常是合理降風險方式；但若騷擾、真實資料或威脅升級，仍需升級求助。
2. 刪除「駭客不可能光靠聊天入侵」這種過度絕對的技術敘述，改成不要因恐嚇主動交出對方原本沒有的內容，並可查證技術威脅。
3. 陌生玩家原稿第三格已明確說「知道學校＋明天校門口堵人＋打到住院」，這裡已經是人身安全紅線，不能等第五格才找大人。
4. 肉搜階段把紅燈從「害怕求饒」改成「主動替對方驗證真實資訊」；害怕本身不是錯誤。
5. 刪除「多數網路屁孩聽到法律就會收斂」及直接斷言「已觸犯法律」的設計，避免鼓勵學生留在聊天室與威脅者鬥法。
6. 第四、第五階段保留五格故事，但改成「已經求助後的安全安排與威脅升級」，而不是拖到最後一格才第一次求助。
7. 165 不作為立即人身危險的主要緊急處理管道；若疑似有人正在住家附近或存在立即危險，應由身邊大人協助聯絡適當緊急管道。

# 關卡一｜跨國網友

**情境：** 認識半年、從未視訊過的跨國網友，突然說準備了一份驚喜。

**宇哲：**「寶貝，下個月我就能飛去台灣找你了！我偷偷挑了一條很貴的名牌項鍊要先寄給你當情人節禮物，想給你一個大驚喜！🎁」

- 🟢 **綠燈｜拒收貴重物品**

**宇哲：**「可是天啊……物流公司剛說包裹被台灣海關扣留了！因為是貴重物品，需要先代墊 5,000 元的『清關保證金』才能放行，你能先幫我嗎？」

  「5000 也太多了吧，我一個月零用錢才 1000，我沒錢啦。」

- 🟢 **綠燈｜拒絕私下付款並準備查證**  
  「我不會照你傳的帳號匯錢。真的有費用我自己去查物流或官方資料。」  
  **回饋：** 關鍵不是背出海關流程，而是不要使用對方提供的付款方式來證明對方是真的。

  「我真的生不出錢啊，不然你自己想辦法？」  
  **回饋：** 這本來就不是你必須接下來的問題。先把自己從付款壓力裡退出來。

**宇哲：**「（傳來一個自稱海關人員的 LINE 帳號）他說如果不繳清，你這個收件人會被通報警察抓起來！你快點加他！」

## 階段 5｜翻臉恐嚇

**星辰：**「好吧，那你把你的手機定位或家裡地址傳給我，我買宵夜掛在你家門口總可以了吧？」

  「不用啦，我現在真的吃不下，而且我也懶得下樓拿。」

  **回饋：** 不需要等照片真的被散布才求助。影像威脅本身就值得讓可信任的人知道，尤其如果影像涉及私密內容。

## 階段 3｜具體人身威脅
**阿豹：**「找人幫忙？我早就知道你讀哪一班了。明天放學我就找人去校門口堵你，看你還敢不敢這麼囂張！」

- 🔴 **紅燈｜答應私下見面談判**  
  「那……我們明天在校門口對面的超商私下談談好嗎？」  
  **回饋：** 對方已經提出具體地點與堵人威脅，不要再安排單獨見面。

- 🟡 **黃燈｜找同學結伴，但不只靠同學**  
  「（先跟好朋友說）『他說明天要堵我，你先不要讓我一個人走。』」  
  **回饋：** 找朋友陪伴是很自然的安全反應，但這時不能只靠同學扛，還要讓能安排安全措施的大人知道。

- 🟢 **綠燈｜立即讓能介入的人知道**  
  「（不再和阿豹談判，把截圖交給家人或學校可信任的大人）『他知道我的學校，說明天放學要來堵我。』」  
  **回饋：** 這格已經跨越人身安全紅線。重點是讓明天的離校、接送與現場安全有人提前安排，而不是等他真的出現。

## 階段 4｜在已求助後繼續勒索
**阿豹：**「怕了吧？現在立刻去超商買 5,000 元點數當『分手費』傳給我，不然我明天照樣去堵你，照片也照發！」

- 🔴 **紅燈｜用付款交換安全**  
  「如果我給你點數，你真的就不來、也不發照片嗎？」  
  **回饋：** 已經出現威脅後，不要再用金錢交換對方的承諾。付款不等於風險會消失。

- 🟡 **黃燈｜不付款、不再談價**  
  「我哪有 5000 元，不要再跟我要了。」  
  **回饋：** 用「沒錢」擋掉付款可以，但因為前一格已經有人身威脅，這時不要只靠話術處理；讓先前求助的人知道威脅又升級了。

- 🟢 **綠燈｜停止私下談判，補充新證據**  
  「（不付款，把新的勒索訊息一起交給正在協助自己的大人／相關管道）」  
  **回饋：** 你不需要自己跟他談出一個價格。新出現的勒索訊息就是新的資訊，交給正在協助你的人處理。

## 階段 5｜倒數散布
**阿豹：**「你再不給，我倒數三秒鐘就要發照片了！3……2……1……」

- 🔴 **紅燈｜慌張刪除所有紀錄**  
  「（嚇到把對話、照片和帳號資訊全部刪掉）」  
  **回饋：** 很想把可怕的東西全部刪掉很正常，但先保留必要的威脅紀錄，後續求助或申訴才有依據。

- 🟡 **黃燈｜先離開訊息轟炸**  
  「（把手機交給家人／可信任的大人，自己先離開螢幕冷靜一下）」  
  **回饋：** 你不必親眼盯著倒數。已經有人一起處理時，暫時離開螢幕也是保護自己。

- 🟢 **綠燈｜保留必要證據並使用適當協助管道**  
  「（保留帳號、威脅內容與必要截圖，不再付款或談判；由大人陪同依影像性質與威脅狀況尋求警方、平台申訴或其他適當協助）」  
  **回饋：** 最重要的是不要再被倒數逼著答應條件。先保留必要資訊，再依實際狀況處理人身威脅與影像散布問題。

## 本輪微調紀錄
1. 原稿第一階段綠燈「點數的錢我可以存錢還你」會預先承認學生欠款，因此改成「若有爭議另外處理」，不把分手和付款綁在一起。
2. 第二階段已經出現「散布照片」威脅，不應只教學生嗆回「犯法、我就報警」。改成先保存威脅、停止談條件、找可信任的人支持。
3. 不把「求饒」本身說成會造成對方繼續勒索；害怕與求饒是可以理解的反應。紅燈是因恐懼而答應金錢、見面或其他要求。
4. 第三階段「知道學校／班級＋明天校門口堵人」正式跨越人身安全紅線，立即啟動家人／學校等能實際介入者。
5. 第四、第五階段改成建立在「第三階段已求助」的連續故事上，不讓學生明明已經找人協助，下一格又突然回到獨自跟對方討價還價。
6. 保留「我沒錢」這種真實黃燈策略，但提醒它只能擋付款，不能取代對既有人身威脅的處理。
7. 不直接把所有照片威脅一律寫成同一種「數位性別暴力」處置；照片內容不同，適合的申訴／協助管道也可能不同，因此最終文字保留彈性。
8. 刪除「完美判斷／神操作／唯一解」等過度 AI 式評語。

# 關卡二｜懂你的陌生人
**主題：** 情緒脆弱時的陌生人接近與秘密邀約  
**對方：** 網友「建哥」（看到你的低落限動後主動私訊的陌生成年人）  
**情境：** 你剛因為成績跟家人大吵一架，發了一則很難過的黑底限動，這時收到陌生網友私訊。

## 階段 1｜過度共情
**建哥：**「看到你的限動了，你爸媽太過分了吧！只看成績根本不在乎你的感受，你一定覺得很委屈對不對？」

- 🔴 **紅燈｜把離家計畫和位置一起告訴陌生人**  
  「對啊！我真的想離家出走，我現在就在 XX 路這邊……」  
  **回饋：** 難過、想抱怨都不是錯；真正提高風險的是把自己正處於低潮、準備離家和所在位置一起交給陌生人。

- 🟡 **黃燈｜普通抱怨**  
  「就吵架而已啦，覺得很煩。」  
  **回饋：** 抱怨一下很正常，而且你沒有把住哪裡、要去哪裡之類的資訊一起交出去。

- 🟢 **綠燈｜禮貌結束話題**  
  「謝謝關心，我現在想自己靜一下。」  
  **回饋：** 可以接受關心，也可以不把自己的脆弱狀況繼續交給陌生人。

## 階段 2｜要求保密
**建哥：**「全世界只有我懂你。這件事你先別跟同學朋友說，我們兩個人知道就好，我聽你說。」

- 🔴 **紅燈｜答應把所有支持者排除在外**  
  「好……反正其他人都不懂，我只跟你講。」  
  **回饋：** 陌生成年人特別要求你不要讓朋友、家人或其他人知道，是很值得警覺的訊號。

- 🟡 **黃燈｜裝傻反問**  
  「蛤？為什麼不能跟朋友說？這又沒什麼。」  
  **回饋：** 這個反問很好。當一段關係突然要求「只能我們知道」，先別急著照做。

- 🟢 **綠燈｜保留自己的支持網**  
  「我有事本來就會跟朋友聊啊，我不會只跟一個網友講。」  
  **回饋：** 不讓任何一個陌生人把你和原本信任的人隔開，會安全很多。

## 階段 3｜深夜邀約
**建哥：**「你家氣氛那麼糟，要不要出來透透氣？我幫你叫車、付車錢，帶你去吃宵夜，不要委屈自己了。」

- 🔴 **紅燈｜秘密離家赴約**  
  「好……那我偷偷溜下去，你幫我叫車喔。」  
  **回饋：** 陌生成年人、深夜、情緒低落、秘密離家同時出現時，風險已經很高。

- 🟡 **黃燈｜懶惰遁**  
  「太晚了啦，我懶得換衣服出門。」  
  **回饋：** 很實用。你不需要跟他辯論，只要讓自己留在安全的地方就已經降低風險。

- 🟢 **綠燈｜拒絕見面**  
  「不用，我今天不會出去，也不會跟不熟的人單獨見面。」  
  **回饋：** 很清楚。免費請客或車錢都不值得拿人身安全交換。

## 階段 4｜邀請到私人住所
**建哥：**「你防備心太重了吧？不然來我家客房睡一晚，我絕對不碰你，明早再送你去學校，我發誓！」

- 🔴 **紅燈｜因為保證而前往陌生人的家**  
  「你都發誓了……好吧，只住一晚喔。」  
  **回饋：** 對方的保證無法替你控制陌生私人空間裡會發生什麼。不要用一句誓言交換自己的安全。

- 🟡 **黃燈｜直覺拒絕**  
  「去陌生人家很怪欸，我才不要。」  
  **回饋：** 這句就夠了。覺得怪、不想去，本身就是可以拒絕的理由。

- 🟢 **綠燈｜結束邀約**  
  「我不會去陌生網友家過夜。不要再約我了。」  
  **回饋：** 對方已經從安慰一路推到秘密見面和過夜，現在可以直接把邀約停掉。

## 階段 5｜翻臉與收尾
**建哥：**「我費盡心思想逗你開心，你把我當壞人防？好心沒好報，隨便你，你就繼續在家裡受氣吧！」

- 🔴 **紅燈｜因為內疚改變決定**  
  「對不起啦你別生氣！那我下樓就是了……」  
  **回饋：** 他生氣不代表你需要赴約。原本覺得不安全的事，不會因為對方翻臉就突然變安全。

- 🟡 **黃燈｜關掉聊天室休息**  
  「（不再回覆，手機開勿擾，先去睡覺）」  
  **回饋：** 可以。只要你沒有赴約，也沒有繼續交出位置資訊，先離開這段壓力很合理。

- 🟢 **綠燈｜停止接觸並讓可信任的人知道**  
  「（保留必要訊息後封鎖；如果對方知道自己的真實資料或仍持續聯絡，就告訴家人或其他可信任的大人）」  
  **回饋：** 沒有具體威脅時，封鎖可以是結尾；但這是陌生成年人曾經邀未成年人秘密離家、到私人住所，如果他掌握真實資料或持續接觸，不必自己扛。

# 關卡三｜讓票社團
**主題：** 熱門票券、付款與個資詐騙  
**對方：** 陌生帳號「售票站長」  
**情境：** 你一直搶不到最愛偶像的演唱會門票，突然有人私訊說有原價票可以讓出。

## 階段 1｜超想要的票
**售票站長：**「你好，請問還在求票嗎？我朋友臨時有事不能去，這裡有兩張特區前排的公關票，原價讓給真正喜歡的粉絲！」

- 🔴 **紅燈｜因為太想要立刻進入付款流程**  
  「我要我要！你帳號給我，我現在就匯！」  
  **回饋：** 很想搶到票完全可以理解，但越稀有的票越容易讓人來不及確認交易方式。

- 🟡 **黃燈｜先懷疑一下**  
  「真的假的？有這麼好康的事？」  
  **回饋：** 有停一下很好。接下來重點是查交易方式，而不是只聽對方保證。

- 🟢 **綠燈｜要求使用較可查證的正式交易方式**  
  「可以走官方轉讓／退票機制，或有保障的交易方式嗎？」  
  **回饋：** 比起單純相信陌生人，優先使用官方或有保障的票券交易流程更安全。

## 階段 2｜催你付訂金
**售票站長：**「我在外縣市沒辦法面交啦！而且現在還有三個粉絲在排隊，你要的話立刻匯一半訂金，不然我就讓給別人了！」

- 🔴 **紅燈｜被倒數逼著匯款**  
  「拜託不要讓給別人！我馬上轉帳！」  
  **回饋：** 「現在不付就沒了」很容易讓人放棄查證。越急著催款，越值得先停。

- 🟡 **黃燈｜拖一下**  
  「我現在沒空弄轉帳欸，晚點再說啦。」  
  **回饋：** 拖延能幫自己脫離當下的催促。等情緒降下來，再決定還要不要交易。

- 🟢 **綠燈｜不接受陌生人私下訂金流程**  
  「如果只能私下先匯訂金，那我不要了。」  
  **回饋：** 放棄一張票很可惜，但比在無保障的流程裡賭一把安全。

## 階段 3｜身分證與票券截圖
**售票站長：**「（傳來身分證照片和票券截圖）你看，這是我的身分證跟票，我不是詐騙啦！這樣總可以信任我了吧？」

- 🔴 **紅燈｜把圖片當成交易保證**  
  「有身分證就沒問題了，我現在匯。」  
  **回饋：** 身分證照片、票券截圖本身不能證明傳訊息的人就是本人，也不能保證票券有效。

- 🟡 **黃燈｜吐槽圖片也可能不可靠**  
  「現在圖片那麼好改，誰知道是不是真的。」  
  **回饋：** 沒錯。圖片可以被盜用、修改或重複使用，不要只靠一張圖做付款決定。

- 🟢 **綠燈｜回到交易機制判斷**  
  「就算照片是真的，我還是只走有保障的交易方式。」  
  **回饋：** 這個判斷更耐用。不要跟陌生人比誰比較會驗照片，直接選擇能降低交易風險的流程。

## 階段 4｜反過來索取你的證件
**售票站長：**「你防備心這麼重，我才怕你是來鬧的。不然換你拍學生證和存摺封面給我看，證明你是真的粉絲我才賣你。」

- 🔴 **紅燈｜交出不必要的證件與金融資料**  
  「好啦，我拍學生證跟存摺給你看。」  
  **回饋：** 買票不需要把這些資料交給陌生人。證件與帳戶資訊外流後，可能被拿去做其他冒用或詐騙用途。

- 🟡 **黃燈｜嫌麻煩直接退出**  
  「買個票還要給存摺？太麻煩了吧，那我不買了。」  
  **回饋：** 這次怕麻煩真的幫上忙了。要求越來越奇怪時，直接不買完全可以。

- 🟢 **綠燈｜拒絕提供不必要資料**  
  「買票不需要給你學生證跟銀行資料，我不會傳。」  
  **回饋：** 很清楚。只提供完成合理交易真正需要的資料，不用為了證明自己而多交個資。

## 階段 5｜抹黑恐嚇
**售票站長：**「浪費我的時間！你不買我就去社團發文黑你，說你是騙子，讓你以後都買不到票！」

- 🔴 **紅燈｜因為怕被黑而付款**  
  「不要亂發文啦……好，我買就是了。」  
  **回饋：** 不要因為陌生人的抹黑威脅，就回頭進入原本已經覺得可疑的付款流程。

- 🟡 **黃燈｜先停止接觸並檢查公開資訊**  
  「（不回覆，把帳號設成私人，看看自己有沒有公開太多資料）」  
  **回饋：** 如果擔心被騷擾，先縮小公開資訊很實際；但不用因為一句恐嚇就認定對方一定掌握你的資料。

- 🟢 **綠燈｜保留必要紀錄並封鎖／檢舉**  
  「（保留必要對話後封鎖、向平台檢舉；若仍擔心交易詐騙，可用 165 等可靠管道查證）」  
  **回饋：** 沒匯款、沒交證件，已經守住最重要的風險。需要時再使用平台或反詐管道確認，不必陪對方繼續吵。

## 本輪微調紀錄
1. 「懂你的陌生人」第一格不把「難過、抱怨、想離家」本身當成學生的錯；紅燈改成向陌生人同時透露脆弱狀態、離家意圖與位置等可利用資訊。
2. 保留「懶得換衣服」「去陌生人家很怪」等真實國中生策略。
3. 陌生成年人已連續出現「要求保密 → 深夜邀約 → 私人住所過夜」，因此第五格雖可封鎖結案，但若對方掌握真實資料或持續接觸，仍應讓可信任的大人知道；不把「沒有明講恐嚇」誤寫成完全沒有安全風險。
4. 票券篇第一格不把「超開心、很想要票」判成危險；紅燈改成因興奮立刻進入付款。
5. 刪除「面交就是第一道防線」的單一規則。面交也可能有假票、重複票等問題；教材改為優先官方轉讓／退票或有保障的交易機制。
6. 刪除「沒看到實體票絕對不能匯款」等過度簡化敘述，重點放在陌生人私下訂金與無保障付款流程。
7. 身分證照片／票券截圖不直接判定一定是假，而是教學生：圖片不能證明傳訊息者身分，也不能保證票券有效。
8. 原稿「傳學生證＋存摺就會變成人頭帳戶、背刑責」過度跳躍，已改成較準確的「資料可能被冒用或用於其他詐騙」。
9. 第五格不要求每個可疑賣票帳號都一定撥 165「通報」；可先封鎖／平台檢舉，需要確認詐騙疑慮時再使用可靠反詐管道。

# 關卡四｜廁所裡的秘密
**主題：** 電子煙與同儕誘惑  
**對方：** 同班同學「阿威」  
**情境：** 下課時間，阿威突然小聲叫你跟他去走廊盡頭的身障廁所。

## 階段 1｜神祕邀約
**阿威：**「欸，你等一下跟我去三樓的身障廁所，我有一個超酷的新玩具給你看，保證好玩。」

- 🔴 **紅燈｜明知對方刻意躲人仍直接跟去**  
  「幹嘛這麼神祕？好啦，走啊。」  
  **回饋：** 不是「去廁所」本身危險，而是對方刻意把你帶到不容易被別人看到的地方、又不肯先說要做什麼，值得多停一下。

- 🟡 **黃燈｜懶惰遁**  
  「我現在超想睡覺的，懶得走過去啦。」  
  **回饋：** 很實用。你甚至不用知道他到底想幹嘛，單純不跟去就已經避開後面的壓力。

- 🟢 **綠燈｜先問清楚**  
  「什麼東西不能在這裡講，要跑去廁所？」  
  **回饋：** 先問目的，不因為「很酷、很神祕」就跟著走。

## 階段 2｜拿出電子煙
**阿威：**「吼，來啦！（拿出一個像隨身碟的東西）最新的電子煙啦，水蜜桃口味的。我這顆聽說沒尼古丁，你吸一口看看。」

- 🔴 **紅燈｜因為對方說沒尼古丁就嘗試**  
  「真的沒尼古丁喔？那我吸一口看看。」  
  **回饋：** 不要只靠同學一句「這顆沒尼古丁」判斷內容物。來路不明的電子煙／煙彈成分不一定能從外觀看出來，也沒有必要拿自己試。

- 🟡 **黃燈｜用當下身體狀況推掉**  
  「不要啦，我最近喉嚨很不舒服，吸了等等一直咳。」  
  **回饋：** 可以。想用一個順口理由先拒絕完全沒問題；不需要為了證明勇敢而試。

- 🟢 **綠燈｜直接不碰**  
  「我不抽這個，裡面到底是什麼我也不知道。」  
  **回饋：** 這句就夠了。不必跟對方辯成分，只要不想碰就可以拒絕。

## 階段 3｜同儕激將
**阿威：**「你是小學生嗎？我們這群大家都在抽欸！怕被老師抓喔？有夠俗辣，是不是不敢啊？」

- 🔴 **紅燈｜為了證明自己而吸**  
  「誰說我不敢？給我啦，我抽給你看！」  
  **回饋：** 這時真正控制你決定的不是你自己，而是「怕被笑」。沒必要用身體替面子買單。

- 🟡 **黃燈｜直接認俗辣**  
  「對啦我俗辣，我超怕被記過，你們自己抽。」  
  **回饋：** 很好用。只要你不接「敢不敢」這顆球，激將法就很難繼續。

- 🟢 **綠燈｜不接受這個比賽**  
  「你要抽是你的事，我不要。這跟敢不敢沒關係。」  
  **回饋：** 不需要證明自己比較勇敢，自己的選擇自己決定。

## 階段 4｜開始推銷
**阿威：**「好啦，這口免費請你。你覺得不錯的話，以後菸彈可以找我買，算你便宜。」

- 🔴 **紅燈｜因為免費而試**  
  「免費喔？那我就試這一次。」  
  **回饋：** 免費不會讓內容物變得比較安全，也不需要因為「只試一次」就勉強自己碰不想碰的東西。

- 🟡 **黃燈｜裝窮**  
  「我連飲料錢都快沒了，哪有錢買這個。」  
  **回饋：** 這招可以。先把推銷擋掉、讓自己離開這個情境，比跟他爭論有用。

- 🟢 **綠燈｜結束交易話題並離開**  
  「不用，我不碰也不買，我先回教室了。」  
  **回饋：** 不試、不買、離開現場，風險直接往下降。

## 階段 5｜擋門與威脅
**阿威：**「（擋在門口）你如果敢走出去亂講，我們這群一定每天找你麻煩！」

- 🔴 **紅燈｜在狹小空間動手硬闖**  
  「你給我滾開！信不信我揍你！」  
  **回饋：** 現在最重要的是安全離開，不需要把局面升級成肢體衝突。

- 🟡 **黃燈｜先口頭安撫換取離開**  
  「好啦，我現在不講，你先讓我出去。」  
  **回饋：** 可以。為了先脫離被擋住的空間，暫時順著說不代表你之後永遠不能求助。

- 🟢 **綠燈｜脫身後找能介入的人**  
  「（安全離開後找家人或學校裡信任的大人）『剛剛有人拿電子煙叫我試，還擋著門威脅我不要說，我有點怕。』」  
  **回饋：** 這時紅線不是「看到別人抽電子煙」本身，而是你已經被擋住去路、受到威脅。先脫身，再讓能處理校園安全的人知道。

# 關卡五｜為了流量密碼
**主題：** 危險惡作劇、同儕義氣與旁觀者決策  
**對方：** 好朋友「小軒」  
**情境：** 小軒想拍一支會爆紅的惡作劇短影音，要你幫忙。

## 階段 1｜危險企劃
**小軒：**「欸！我想到一個一定爆紅的企劃！等一下老師要坐下去的時候我把椅子抽掉，你幫我拿手機錄！」

- 🔴 **紅燈｜因為覺得好笑就加入**  
  「聽起來超好笑！好啊，我幫你拍。」  
  **回饋：** 抽椅子可能讓人重摔受傷。影片再好笑，都不值得拿別人的身體去賭。

- 🟡 **黃燈｜先把自己的工作推掉**  
  「我拍影片超手震的，你找別人啦。」  
  **回饋：** 先不加入是有用的一步。不過你已經知道有人可能馬上受傷，接下來還要看看這個計畫會不會真的繼續。

- 🟢 **綠燈｜直接指出危險**  
  「不要啦，真的摔傷怎麼辦？我不拍。」  
  **回饋：** 很夠用了。不需要講大道理，先拒絕參與。

## 階段 2｜義氣施壓
**小軒：**「哪有那麼容易受傷，網路上一堆人都這樣拍。你是不是好兄弟？只是拿手機拍一下也不幫？」

- 🔴 **紅燈｜為了朋友加入**  
  「好啦好啦，只拍這一次喔。」  
  **回饋：** 「只是拍」仍然是在幫這個危險計畫進行。不要因為怕被說不夠朋友就加入。

- 🟡 **黃燈｜硬體遁**  
  「我手機快沒電了，而且容量滿了，沒辦法錄啦。」  
  **回饋：** 很生活化的拒絕方式。先把自己從計畫裡抽掉，不必跟朋友正面吵。

- 🟢 **綠燈｜拒絕幫忙**  
  「你要拍別的我可以幫，這個會害人受傷，我不要。」  
  **回饋：** 把「不幫這件事」和「不當朋友」分開，不需要接受他的義氣考題。

## 階段 3｜「出事我扛」
**小軒：**「反正動手的是我，被抓到我自己扛。你只是拍而已，又不是你抽椅子。」

- 🔴 **紅燈｜因為對方承諾負責就加入**  
  「你說的喔，出事你自己扛，那我幫你拍。」  
  **回饋：** 別人說「我扛」不能替你消除自己參與其中可能帶來的校規、責任或其他後果。

- 🟡 **黃燈｜先離開現場**  
  「隨便啦，我先去廁所，不陪你弄。」  
  **回饋：** 離開能避免自己加入，但現在你已經知道危險行為可能真的會發生，還不能只用「我沒參加」判斷事情結束了。

- 🟢 **綠燈｜再次拒絕並提醒停止**  
  「你自己扛也沒用，人真的摔傷就麻煩了。不要弄啦。」  
  **回饋：** 重點不是背出「共犯」兩個字，而是看懂：你知道這件事可能傷人，而且還來得及阻止。

## 階段 4｜換成另一個同學
**小軒：**「你不幫就算了，我自己架手機！我等一下去弄隔壁班那個同學，他摔倒一定超好笑。」

- 🔴 **紅燈｜明知即將有人受傷仍只當沒自己的事**  
  「隨便你，反正不是我弄的。」  
  **回饋：** 你沒有加入是好事，但現在已經知道一個具體的危險動作即將對別人發生，事情的風險變了。

- 🟡 **黃燈｜找其他同學一起阻止**  
  「（去找幾個同學）『欸小軒真的要去抽別人椅子，我們先叫他不要弄啦。』」  
  **回饋：** 找同伴一起阻止是合理的第一反應；如果時間夠、現場安全，也可能讓他打消念頭。

- 🟢 **綠燈｜立即找能阻止現場的人**  
  「（直接去找附近老師或其他能立刻制止的大人）『小軒等一下要故意抽同學椅子，可能會摔傷。』」  
  **回饋：** 紅線其實在這一格就出現了：有明確對象、明確動作，而且可能馬上發生。不要為了等第五格才求助。

## 階段 5｜被發現你阻止了
**小軒：**「你真的去找人喔？你很破壞氣氛欸！你再管我的事，我就跟你絕交！」

- 🔴 **紅燈｜為了保住友誼改口幫忙掩護**  
  「好啦對不起，我跟老師說我剛剛亂講的，你不要跟我絕交。」  
  **回饋：** 你不用為了留住朋友，把已經知道的危險說成沒發生。

- 🟡 **黃燈｜不吵架，先拉開距離**  
  「喔……你現在很氣就先不要聊，晚點再說。」  
  **回饋：** 不需要在現場跟他辯誰比較有義氣。危險已經有人介入，現在可以先把衝突降下來。

- 🟢 **綠燈｜接受朋友可能生氣，但不撤回安全行動**  
  「你要生氣就先氣吧，我只是不要真的有人摔傷。」  
  **回饋：** 這格不是「當英雄」，而是承受一點朋友的不爽，換掉一個可能造成受傷的惡作劇。前一格已經找人阻止，這裡不需要再重複通報一次。

## 本輪微調紀錄
1. 電子煙篇不再宣稱「通常含高濃度尼古丁甚至毒品」「一口就可能上癮或昏迷」；改成更耐用的風險概念：不要靠同學口頭保證判斷來路不明產品的內容物，也不必親自試。
2. 黃燈仍保留「身體不舒服」擋箭牌，但不替學生虛構氣喘等疾病。
3. 刪除「免費是為了讓你上癮成為提款機」等對同學動機的過度推定；只教學生免費不會降低風險。
4. 電子煙篇第五格真正跨紅線的是「擋門＋威脅」，因此保留先口頭安撫脫身，再求助的策略。
5. 危險惡作劇篇刪除「抽椅子會尾椎碎裂／終身癱瘓」等戲劇化特定結果，改為可能造成重摔與嚴重傷害。
6. 刪除「幫忙錄影就是法律上的共犯」的絕對法律判定。是否涉及法律責任取決於實際參與方式與具體情節；教材只需讓學生理解參與、協助可能帶來校規或其他責任。
7. 原稿真正的人身傷害紅線其實在第四格就已經成立：小軒說要對一名具體同學實施抽椅子，而且即將行動。因此綠燈在第四格就找能立即制止的人，不為了五格結構故意拖延。
8. 第五格改成「求助後的友誼壓力」：學生不必再次通報，只要不因怕絕交而撤回安全行動。
9. 移除「胖的同學摔倒一定有喜感」的身材羞辱設定，危險性不需要靠嘲笑受害者體型來成立。
10. 移除「真英雄／完美／最正確」式結語，維持整套教材的降風險而非英雄主義。

# 異想聊天室｜青春生存遊戲：人際危機大考驗
## 關卡一｜群組霸凌
**對方：** 同學「語晴」

### 階段 1｜試探
**語晴：** 在群組開始講小安的壞話，試探你要不要一起附和。

- 🔴 **紅燈｜跟著一起嘲笑／補充八卦**
  **回饋：** 跟著加入會讓自己也進入攻擊別人的行列。
- 🟡 **黃燈｜敷衍帶過**
  「喔……我沒注意欸。」
  **回饋：** 不跟著起鬨，先把自己抽離。
- 🟢 **綠燈｜裝傻不接球**
  「蛤？是喔，我上課都在發呆沒注意看欸。」
  **回饋：** 這招可以。不接八卦、不幫忙擴散，就已經把風險降下來。

### 階段 2｜要求轉發
**語晴：** 要你一起轉發攻擊小安的限動／貼文。

- 🔴 **紅燈｜怕被排擠而照做**
  **回饋：** 一旦轉發，你就從旁觀變成實際參與散布。
- 🟡 **黃燈｜找理由拖掉**
  「我很少發這種東西啦。」
  **回饋：** 用自己的使用習慣擋掉也可以。
- 🟢 **綠燈｜用興趣當擋箭牌**
  「呃……我不想發欸，我版面只想發動漫跟遊戲，不想發別的。」
  **回饋：** 很自然。你不用替任何人公開攻擊別人。

### 階段 3｜情緒勒索
**語晴：**「你不發就是跟她一夥的啦！」

- 🔴 **紅燈｜為證明站隊而加入**
  **回饋：** 不需要靠攻擊別人證明自己是哪一邊。
- 🟡 **黃燈｜先拖延離開聊天室**
  「等一下啦，我媽在叫我。」
  **回饋：** 先離開壓力現場也可以。
- 🟢 **綠燈｜洗澡遁**
  「沒啦，我只是不想弄這個。我媽在叫我了，我先去洗澡喔，掰！」
  **回饋：** 不正面開戰，也沒有照做，成功把自己抽離。

### 階段 4｜威脅連你一起公審
**語晴：** 開始說如果你不配合，就連你一起貼出來公審。

- 🔴 **紅燈｜因為害怕而回頭參與**
  **回饋：** 被威脅會害怕很正常，但不用因此加入攻擊別人。
- 🟡 **黃燈｜先找朋友一起想**
  「（先不回群組）把對話截圖留著，傳給比較信任的朋友：『欸她現在說要連我一起公審，我有點不知道怎麼辦。』」
  **回饋：** 有點不對勁了。先別急著回嗆，把訊息留著，再找一個信任的人一起想辦法，比自己在聊天室裡硬撐安全。
- 🟢 **綠燈｜停止參與並保留訊息**
  **回饋：** 不再被群組節奏拖著走，同時留下需要的資訊。

### 階段 5｜出現校門口威脅
**語晴：** 威脅要在學校／校門口找你麻煩。

- 🔴 **紅燈｜自己赴約處理**
  **回饋：** 已經出現現實人身威脅，不需要自己去談判。
- 🟡 **黃燈｜只找朋友陪著**
  **回饋：** 有朋友陪會比較安心，但如果真的可能有人堵你，不能只靠同學處理。
- 🟢 **綠燈｜把威脅交給能介入的人**
  「（不理她）把這段截圖拿給爸媽或信任的老師看，說：『同學傳這個恐嚇我，我有點害怕。』」
  **回饋：** 這次不能只裝死了。已經跨到現實安全紅線，讓能實際保護你的人介入。
