【名詞 - 複數變化的基本規則】

班級：__________ 姓名：__________

💡 重點：有兩個以上的時候，尾巴要加「s」或「es」！

1. 一般名詞：直接加「s」

one cat → two cats 🐱

one apple → three apples 🍎

(絕大多數名詞在複數時直接加上 s 即可)

2. 字尾是 s, x, ch, sh：加上「es」

one bus → two buses 🚌

one box → three boxes 📦

(尾音太難發音時，多加一個字母 e 比較好唸)

LEVEL 1 暖身判讀：配對正確嗎？ (正確選 ◯，錯誤選 ✕)
(      )
1. I have two cats. (我有兩隻貓。🐱)
(      )
2. He wants three boxs. (他想要三個箱子。📦)
(      )
3. Look! Five dogs are running. (看！五隻狗正在跑。🐶)
LEVEL 2 進階挑戰：點選上方單字，填入正確空格中
🖐️ 選取字卡：

1. I bought four ________ at the market. ( 🍎 x 4 )

我在市場買了四個蘋果。

2. We see three ________ on the street. ( 🚌 x 3 )

我們在街上看見三輛公車。

3. The two ________ are crying. ( 👶 x 2 )

這兩個嬰兒正在哭泣。

LEVEL 3 綜合選擇題：選出最正確的答案

1. (      ) There are many ______ in the kitchen. ( 🥚 x 10 )

2. (      ) I see two ______ in the box. ( 🦊 x 2 )

3. (      ) The boy has ten ______ on the desk. ( ✏️ x 10 )

🔑 本講義教師解答：【Level 1】1. ◯   2. ✕   3. ◯   【Level 2】1. apples   2. buses   3. babies   【Level 3】1. (B)   2. (A)   3. (B)
