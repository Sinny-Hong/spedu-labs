this／that＋is；these／those＋are。
例：This is a cat.／These are two cats. 請選出括號內正確的單字。

1.

2.

3.

4.

5.
( / ) are three apples.
6.
Those ( / ) two dogs.

6-2 句型與改寫

依照提示，將完整句子寫在底線上。
例：This / be / apple → This is an apple.

1.

→ This is an apple.
