# 文法主題互動式電子講義｜母版使用規格

> 製作新講義前，先閱讀本文件與 `grammar_topic_master_v1_3.html`。本文件記錄該母版目前實際使用的標記、樣式與程式；教材內容仍以教師確認的最新正式 Word 為準。

## 01｜任務定位

每份文法講義都是完整、獨立的單一 HTML。製作新教材時，複製 `grammar_topic_master_v1_3.html` 成新檔，再在新檔內填入該份教材自己的 HTML、CSS、JavaScript 與內容。不要直接修改母版來製作新教材，也不要建立會使既有講義跟著改變的跨講義共用程式依賴。母版中的示範題僅用於測試元件，絕非新教材題庫。

## 02｜來源優先順序

1. **最新正式 Word**：教材內容、章節、小節、文字、規則、例題、提示、表格、圖片、題目及答案的唯一依據。
2. **HTML 母版**：畫面、元件標記、操作、批改、原位解答、導覽與學生／教師列印的依據。
3. **本文件**：AI 複製及填寫母版的操作規範；若與實際母版程式不一致，先查明原因並回報。

先確認 Word 的正式版本。Word 與母版不能直接對應時，列出落差並詢問教師；不得自行刪除、改寫或簡化教材來遷就母版。

## 03｜元件使用規格

母版以 `<section class="section quiz" id="..." data-type="...">` 包住互動題組。題組標頭是 `.section-head`、`h3` 與 `.actions`，按鈕以 `data-act="grade"`（批改）、`hint`（提示）、`clear`（清空）、`answer`（解答）配置。只有該題型需要的按鈕才放入。批改結果寫入 `.score`。`clear(sec)` 清除整個題組的選擇、提示、解答及分數；`showAnswer(sec, force)` 切換 `.answer-on`，答案維持原作答位置。`grade(sec)` 目前支援 `choice`、`circle`、`match`、`order`；純展示填答使用 `display`，不假裝具備鍵入批改。提示按鈕切換題組的 `.hint-on`，與 `.answer-on` 各自獨立。

所有 `.q` 使用左側 `.q-prefix` 加右側 `.q-main` 的雙欄凸排；長題目在右欄換行。排序題 `.order-prompt`、造句題 `.sentence-zh` 對題號使用凸排，窄螢幕換行後保留作答區縮排。複製題組時，更新不重複的 `id`、題號、`data-correct` 與答案；同一題型可以在不同章節或大題重複，毋須遵守母版示範順序。

| 題型 | 實際資料標記與操作 | 原位解答及功能鍵 |
| --- | --- | --- |
| 是非題 ○／× | `data-type="choice"`；每題 `.q[data-correct="○" 或 "×"]`，`.q-prefix.response .chosen` 是作答括號，兩個 `.choice.tf-choice[data-value]` 供點選。○／× 同尺寸。 | 點選時代號進括號；`grade` 正確變綠、錯誤取消選取；`answer` 將正解顯示在原括號；`clear` 重設。示範鍵：批改、清空、解答。列印隱藏題末 ○／× 按鈕。 |
| 選擇題（二／三／四選一） | `data-type="choice"`；`.q[data-correct="A/B/C/D"]`、`.q-text`、`.options` 內放 2–4 個 `.choice[data-value]`，括號為 `.q-prefix.response .chosen`。 | 點選選項即同步括號；批改、解答、清空同上。示範另有提示鍵，會標示題幹中的 `.hint-word`；各題可有不同提示字。 |
| 圈選題（單選） | `data-type="circle"`；每題 `.q[data-correct]`，在 `.q-main` 內排 `.choice[data-value]`。 | 點選圈選、批改正確變綠／錯誤取消、解答標正解、清空。示範鍵：批改、清空、解答。 |
| 填空題 | `data-type="display"`；`.q` 內用 `.slot`（可選 `.medium`、`.long`），其中 `.placeholder` 保留空位，`.solution` 填正解。 | `answer` 在同一空格顯示正解；示範另有 `.hint-word`、提示、清空。無鍵入批改。 |
| 左右配對題 | `data-type="match"`；左側 `.match-left` 內 `.match-row[data-correct]`、`.match-code .chosen`，右側 `.match-bank` 內 `.bank-opt[data-value]`。先點左題再點右側代號。 | 代號飛入原括號；批改正確變綠、錯誤清掉該題代號；解答顯示各題正確代號；清空。示範鍵：批改、清空、解答。 |
| 表格式填空 | `data-type="display"`；`.plain-table` 的表格儲存格以 `.cell-answer` 裝正解。 | `answer` 在原儲存格揭答；示範鍵：解答。無互動輸入或批改。 |
| 橫向規則表 | `data-type="display"`；`.rule-table` 橫向欄位中的空格使用 `.slot`、`.placeholder`、`.solution`。 | `answer` 在原表格空格揭答；示範鍵：解答。 |
| 句型排序 | `data-type="order"`；每題 `.order-row[data-correct="詞1\|詞2\|..."]`，中文題幹 `.order-prompt`，可點字卡置於 `.word-bank .word-card[data-token]`，作答線 `.word-zone`，完整答案 `.sentence-answer`，列印文字 `.word-bank-print`。正解詞序以半形 `\|` 分隔，必須與字卡的 `data-token` 完全一致。 | 點字卡進作答區呈藍色，點作答區字卡可退回；批改只清除錯誤小題；解答在原作答區顯示完整句子且保留底線；清空。示範鍵：批改、清空、解答。列印詞庫改為斜線分隔文字，不印大型字卡按鈕。 |
| 空白造句（中翻英） | `data-type="display"`；每題 `.sentence-row` 內有 `.sentence-zh`、畫底線的 `.sentence-en`，正解置於 `.solution`。可在同一 `.sentence-en` 內加入 `.sentence-hint`，只填事先確認的英文關鍵字；無提示的題目省略該元素。 | `hint` 以深藍字在原作答線顯示關鍵字，隱藏後恢復空線；`answer` 獨立顯示完整句子，底線保留。示範鍵：提示、解答；需要時可用既有清空鍵。無鍵入批改。 |

不需互動的內容可使用 `.chapter-title`（大標題）、`.section-head h3`（中標題）、一般段落與 `.instruction`（說明）、`.note`（規則及小提示）、`.sample`（例題）、`.plain-table`（一般表格）及 HTML 圖片。圖片需要保留 Word 的內容、說明及替代文字；不能因母版沒有示範圖片而省略。章節目錄由程式掃描 `.chapter-title,.section-head h3` 生成；全冊置於同一 `.book > .paper` 連續捲動。第一頁 `.pagehead` 保留講義標題、班級與姓名；列印頁碼由 `@page` 的 `counter(page)` 產生。

## 04｜AI 允許修改與禁止修改的範圍

**允許：**在新講義的複本中複製、刪除、重排既有題組；調整題組名稱及題數；更換文字、圖片與表格；填入題目、選項、正解及提示；按題型配置母版已支援的功能鍵；因文字長度調整必要欄寬及排版。調整後仍須保留凸排、原位答案及手機／列印可讀性。

**禁止：**自行重寫 `grade`、`showAnswer`、`clear` 等既有批改與解答函式；發明另一套解答顯示方式；把原位答案改到題目下方；改變已定稿題型操作；刪除 Word 的規則、教學提示或例題；自行增減、改寫或補回題庫；為新講義修改其他已完成 HTML；未經確認新增母版不支援的題型。缺少功能時，先列出具體需求並詢問教師。

## 05｜Word 轉電子講義流程

1. 確認最新正式 Word 的檔案與版本。
2. 逐頁盤點章節、小節、規則、提示、表格、圖片、例題、題目、選項與答案，包含短小提示。
3. 建立 Word 每個內容段落與上列母版元件的對照；標示無法直接對應的地方並回報。
4. 複製正式母版成新的獨立 HTML，保留母版原檔。
5. 按 Word 原始順序組裝章節及題組；可重複使用相同題型。
6. 填入原文、題目、選項、`data-correct`、`.solution`、`.sentence-answer`、`.sentence-hint` 等對應資料。
7. 逐項對照 Word，確認所有教學文字、短提示、例題、圖表及題數均未遺漏。
8. 測試點選、排序、配對、批改、提示、清空與原位解答，包含錯題及未作答狀態。
9. 分別檢查學生版與教師版列印；學生版不得洩漏答案，教師版在原位置顯示正解與頁碼。
10. 完成後提供新講義測試連結與驗收摘要，待教師確認。

**內容忠實度優先於自動化程度。題目不好套版時，不能直接省略或簡化。**

## 06｜驗收檢查表

- [ ] Word 與 HTML 的章節、小節及題組順序一致。
- [ ] 各題型題數、選項數與 Word 一致。
- [ ] 沒有漏掉規則、例題、小提示、圖片或表格。
- [ ] 各題 `data-correct`、`.solution`、`.cell-answer`、`.sentence-answer` 與提示正確對應。
- [ ] 九種題型各使用母版對應元件；重複題型正常運作。
- [ ] 批改、提示、清空、解答按鍵依題型配置且運作正常。
- [ ] 顯示／隱藏答案不覆寫學生原作答；取消後可還原。
- [ ] 所有答案都顯示在原作答位置，排序與造句的底線仍在。
- [ ] 各題型及手機換行後仍維持凸排，無水平溢出。
- [ ] 學生版列印不洩漏正解與提示，也不印互動按鈕。
- [ ] 教師版列印在原位顯示正解、詞庫文字與頁碼。
- [ ] 講義可完整向下捲動，章節目錄能跳轉且不改網址。
- [ ] 新講義含自己的 HTML、CSS、JavaScript，不依賴或修改其他講義。

## Topic 專區收錄

`library-topic.html` 的線上掃描及 `topic-manifest.js` 備援清單只收錄 `topic/` 中符合條件的 `.html`。正式母版因此可列在下拉選單；本 Markdown 不會列入，也不在學生講義顯示。入口會優先開啟 `spedu-topic-last-file` 記住的上次教材；不要改成每次強制開啟母版。新增正式講義後應更新備援清單，並確認掃描、切換及獨立開啟都正常。
