1　先辨識：什麼是現在簡單式？

1-1　使用時機：永恆不變的真理，日常狀態或習慣。

① 永恆不變的真理：太陽從東方升起。　The sun rises in the east.

② 日常狀態：我住在臺南。　I live in Tainan.

③ 日常習慣：我每天走路上學。　I walk to school every day.

提醒：every day＝每天，是現在簡單式常見的時間線索；但是沒有時間詞，也可能使用現在簡單式。

1-2　判斷中文：哪些情況使用現在簡單式？

題型：判斷下面的情況是否適合使用現在簡單式。是的選 ○，不是的選 ×。

（ 　 ）1.
我每天七點起床。
（ 　 ）2.
我昨天去公園。
（ 　 ）3.
我住在臺南。
（ 　 ）4.

（ 　 ）5.
我上星期看了一部電影。
（ 　 ）6.
地球繞著太陽運行。
（ 　 ）7.
妹妹現在正在睡覺。
（ 　 ）8.
我每晚十點睡覺。

1-3　判斷英文：這是不是現在簡單式？

題型：現在簡單式選 ○，不是的選 ×；看到時間線索時，把線索圈起來。

2　第一條路線：你我一堆人，不用做變化

2-1　定義：你我一堆人，不用做變化

主詞：I / you / we / they，或兩個以上的人、動物、東西。

句型寫法例句
肯定主詞 + 原形動詞We read books.
否定主詞 + don't + 原形動詞We don't read books.
疑問Do + 主詞 + 原形動詞...?Do you read books?

重點：你我一堆人 → 動詞用原形。

3　第二條路線：他一個人，要做變化

3-1　定義：他一個人，要做變化

he / she / it，或一個人、一個動物、一個東西 → 一般動詞要做變化。

I play soccer. → Amy plays soccer.

We like pizza. → Tom likes pizza.

They study math. → Kevin studies math.

3-2　動詞怎麼變？

照規則把動詞變成「他一個人」使用的形式。

＋s＋es去 y ＋ ies特別記
play → 　playswatch → 　watchesstudy → 　studieshave → 　has
like → 　likeswash → 　washestry → 　tries
read → 　readsgo → 　goesfly → 　flies
eat → 　eatsdo → 　does
規則：一般 +s；s、x、ch、sh、o 結尾 +es；子音 + y → 去 y + ies；have → has。

4　do / does 一出現，動詞打回原形

4-1　定義：do / does 一出現，動詞打回原形

Amy likes pizza. → Amy doesn't like pizza. → Does Amy like pizza?

口訣：do / does 一出現，動詞打回原形。

句型寫法例句
肯定主詞 + V-sTom plays soccer.
否定主詞 + doesn't + VTom doesn't play soccer.
疑問Does + 主詞 + V...?Does Tom play soccer?

提醒：過去式 did + 原形；現在簡單式 do / does + 原形。

4-2　圈出原形動詞

看到 does / doesn't，圈出後面的原形動詞。

1.

2.

3.

4.
Does Kevin ( / ) math?
5.

6.

4-3　句型變化：肯定 → 否定／疑問

看肯定句，把它變成否定句和疑問句。注意：does 出現後，動詞打回原形。

1.
① Amy lives in Tainan.
否定：Amy 　doesn't 　live in Tainan.　【doesn't / live】
疑問：　Does Amy 　live in Tainan?　【Does / live】
2.
② Tom plays soccer.
否定：Tom 　doesn't 　play soccer.　【doesn't / play】
疑問：　Does Tom 　play soccer?　【Does / play】
