將完整句子改寫成否定祈使句。例：Run. → Don't run.

第 5 章｜Please

5-1 Please 的位置

Please 前置Please 後置
Please sit down.Sit down, please.
Please be quiet.Be quiet, please.
Please open the door.Open the door, please.
小提醒：Please 放在句尾時，前面要加逗點。

5-2 Please 位置與逗點

請判斷句子的 Please 位置及標點是否正確。正確選 ○，錯誤選 ×。

（ 　 ）1.
Please sit down.
（ 　 ）2.
Sit please down.
（ 　 ）3.
Be quiet, please.
（ 　 ）4.
Please be careful.
（ 　 ）5.
Open your book please.

5-3 依指定位置組句

例：sit down / please（後置）→ Sit down, please.

1.
open the door / please（前置） → Please open the door.
2.
be quiet / please（後置） → Be quiet, please.
3.
please / stand up（前置） → Please stand up.

第 6 章｜人名與稱呼語

6-1 人名位置與逗點

人名前置人名後置
Amy, sit down.Sit down, Amy.
Ben, be quiet.Be quiet, Ben.
Tom, don't run.Don't run, Tom.
小提醒：人名和主要句子之間，用逗點隔開。

6-2 標點判斷

6-3 依指定位置組句

依提示寫出完整句子。例：Amy / sit down（人名前置）→ Amy, sit down.

1.

2.
Amy / be quiet（後置） → Be quiet, Amy.

第 8 章｜祈使句整合

8-1 找線索與分類

觀察句子，勾選出現的線索；本題可以複選。例：Amy, please don’t run. → Don’t、Please、人名。

題目Don'tBePlease人名
Open the door.
Be careful.
Don't run.
Please sit down.
Amy, stand up.
Don't be noisy.
Please be quiet.
Tom, don't shout.
Amy, please don't be late.
Please open the window, Ben.

沒有出現指定線索的題目，四格都不勾。

8-2 句型整合選擇

選出符合中文或文法的正確答案，將代號填入括號。

（ 　 ）1.
請安靜。
（ 　 ）2.
不要跑。
（ 　 ）3.
Amy，請坐下。

8-3 句型轉換

依指定要求寫出完整句子。例：Run.（否定）→ Don't run.

1.
Sit down.（否定） → Don't sit down.
2.
Be noisy.（否定） → Don't be noisy.
3.
Open the book.（否定） → Don't open the book.
4.
Be late.（否定） → Don't be late.
5.
Come here.（加入前置 Please） → Please come here.
6.
Close the window.（加入後置 Please） → Close the window, please.
7.
Stand up.（加入前置人名 Amy） → Amy, stand up.
8.
Be quiet.（加入後置人名 Ben） → Be quiet, Ben.

8-4 中翻英與碎片提示

根據中文及提示寫出完整祈使句。例：Amy，請坐下。 Amy / please / sit down → Amy, please sit down.

1.
請站起來。｜stand up → Stand up.
2.
不要跑。｜don’t / run → Don't run.
3.
請小心。｜be / careful → Be careful.
4.
不要遲到。｜don’t / be / late → Don't be late.
5.
請開門。｜please / open / the door → Please open the door.
6.
Ben，請安靜。｜Ben / please / be quiet → Ben, please be quiet.
7.
Amy，不要說話。｜Amy / don’t / talk → Amy, don't talk.
8.
請不要吵鬧。｜please / don’t / be noisy → Please don't be noisy.
