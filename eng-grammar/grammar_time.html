【時間詞 - 時間介系詞 past 與 to】

班級：__________ 姓名：__________

💡 核心重點：時間差幾分與過幾分 (past 與 to)！

★ 基礎直接唸

「先唸小時，再唸分鐘」

公式：[小時] + [分鐘]

例 8:10 ➔ eight ten

例 8:50 ➔ eight fifty

past

「過了」幾分 (1~30分)

公式：[分鐘] + past + [這小時]

例 8:10 ➔ ten past eight

to

「差」幾分就幾點 (31~59分)

公式：[差幾分] + to + [下個小時]

例 8:50 ➔ ten to nine (差十分九點)

★ 實用複習： 15 分鐘可以用 quarter 替代喔！ (例 8:15 ➔ quarter past eight)

LEVEL 1 暖身判讀：這樣報時正確嗎？ (正確選 ◯，錯誤選 ✕)
(      )
1. We can say 8:10 is "ten past eight" or "eight ten".
(      )
2. We can say 8:50 is "ten to eight" or "eight fifty".
(      )
3. We can say 8:15 is "quarter past eight".
LEVEL 2 進階挑戰：時鐘報時字卡免打字配對
🖐️ 先選取字卡，再點擊題目空格：

1. It is 9:05. It is five ________ nine.

現在是九點過五分（九點五分）。

2. It is 9:55. It is five ________ ten.

現在是差五分鐘十點（九點五十五分）。

3. It is 10:15. It is a ________ past ten.

現在是十點過了一刻（十點十五分）。

4. It is 10:45. It is a ________ to eleven.

現在是差一刻十一點（十點四十五分）。

LEVEL 3 綜合選擇題：選出最正確的答案

(      ) 1. What time is it? (7:40) It is twenty ______ eight.

(      ) 2. What time is it? (7:10) It is ten ______ seven.

(      ) 3. What time is it? (7:30) It is ______ past seven.

🔑 本講義教師解答：【Level 1】1. ◯   2. ✕   3. ◯   【Level 2】1. past   2. to   3. quarter   4. quarter   【Level 3】1. (B)   2. (A)   3. (C)
