Sinny Spedu Labs Portal V1 測試版

使用方式：
1. 先不要覆蓋原本首頁。
2. 將整個 spedu-portal-v1 資料夾放在電腦任意位置。
3. 直接雙擊 index.html 測試。
4. 確認版面後，再把 index.html、portal.css、portal.js 與 assets 放到 spedu-labs 最外層。
