# Spedu Labs 共用圖檔

所有新版目錄與主頁共用的品牌圖片統一由最外層 `assets/` 引用。

## 正式使用

- `logo-banner.png`：橫式品牌標誌，適用於主目錄與子目錄標題列。
- `logo-round.png`：透明背景圓形品牌標誌，適用於側欄、手機標題列與小尺寸品牌入口。
- `watermark-icon.png`：透明背景浮水印，適用於頁面與卡片背景，不作一般 Logo 使用。

## 舊檔盤點

- `assets/spe-icon2.png`：1536×1536 黑色底圖，不適合白色介面；保留供舊檔追查，新頁面不得引用。
- `eng-115/spe-icon2.png`、`eng-grammar/spe-icon2.png`、`picture/spe-icon2.png`：三份相同的透明圓標；正式共用副本為 `assets/logo-round.png`。
- `eng-115/line-qrcode.png`、`eng-grammar/line-qrcode.png`、`picture/line-qrcode.png`：三份相同的舊橫式發光標誌，目前只供舊版頁面使用。
- 根目錄 `spe-icon1.png`：2 bytes 的無效檔案，不得引用。

舊檔暫不刪除，以免仍在使用的教材失去圖片。新頁面一律使用上述三個正式檔名。
