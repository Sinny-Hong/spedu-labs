# Spedu Labs 共用圖檔

所有新版目錄與主頁共用的品牌圖片統一由最外層 `assets/` 引用。

## 正式使用

- `logo-banner.png`：橫式品牌標誌，適用於主目錄與子目錄標題列。
- `logo-banner-glow.png`：透明背景發光橫標，只供需要保留舊版發光效果的頁面使用。
- `logo-round.png`：透明背景圓形品牌標誌，適用於側欄、手機標題列與小尺寸品牌入口。
- `watermark-icon.png`：透明背景浮水印，適用於頁面與卡片背景，不作一般 Logo 使用。

## 清理紀錄

重複的 `spe-icon2.png`、`line-qrcode.png`、黑底 Logo 與損壞的 `spe-icon1.png` 已完成盤點並移除。原本引用舊檔的頁面已改用上述正式檔名。新版頁面不得自行在子目錄複製品牌圖檔。
