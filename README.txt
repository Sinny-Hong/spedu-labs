週次設定：
在聯絡簿工作表勾選唯一一個啟用學期，首頁日期旁會顯示「學期別・目前週次」。
全部未勾選、同時勾選多個學期，或目前週次空白時，首頁會隱藏週次與本週單字。

重要：
在電腦直接雙擊 index.html 時，部分瀏覽器可能阻擋 Google CSV 跨網域讀取。
請以上傳 GitHub Pages 後的結果作為正式測試依據。
目前 CSV 先對應「今天任務」。聯絡簿、作業缺交、其他分頁需各自發布 CSV 網址後再串接。
